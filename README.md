\# Система измерения и анализа физиологических параметров состояния человека



Автономная система для измерения и анализа физиологических параметров человека на базе \*\*Seeed Studio XIAO nRF52840 Sense\*\*.  

Устройство измеряет \*\*частоту сердечных сокращений (ЧСС)\*\*, \*\*уровень насыщения крови кислородом (SpO₂)\*\*, \*\*частоту дыхания (ЧД)\*\*, \*\*вариабельность сердечного ритма (ВСР)\*\* и \*\*количество шагов\*\*, сохраняя все данные локально на карту microSD – без облачных сервисов и проприетарных ограничений.



\---



\## Возможности



\- Измерение в реальном времени:

&#x20; - \*\*Частота сердечных сокращений\*\* – 40…200 уд/мин

&#x20; - \*\*SpO₂\*\* – 70…100 %

&#x20; - \*\*Частота дыхания\*\* – 5…40 дых/мин

&#x20; - \*\*Вариабельность сердечного ритма (RMSSD)\*\* – 5…300 мс

&#x20; - \*\*Подсчёт шагов\*\* – адаптивный порог + фильтрация по гироскопу

\- \*\*Графики истории\*\* – суточная статистика для ЧСС, ЧД и ВСР

\- \*\*До 5 программируемых будильников\*\* с вибрацией

\- \*\*Автоматическое измерение\*\* при условии наличия контакта с кожей

\- \*\*Хранение всех данных на microSD\*\*

\- \*\*Резервное копирование\*\* счётчика шагов и настроек будильников

\- \*\*Сторожевой таймер\*\* – перезагрузка устройства при сбоея

\## Программное обеспечение и библиотеки



\- \*\*Arduino IDE\*\*

\- Пакет поддержки плат \*\*Seeed nRF52 Boards\*\*

\- Библиотеки из папки `libraries/`, которые необходимо установить:

&#x20; - LVGL – графический интерфейс

&#x20; - TFT\_eSPI – драйвер дисплея

&#x20; - RTClib – работа с RTC (PCF8563)

&#x20; - SdFat – файловая система SD-карты

&#x20; - Seeed Arduino LSM6DS3 – драйвер IMU

&#x20; - SparkFun MAX3010x – драйвер оптического датчика



\### Установка пакета плат Seeed nRF52 Boards



1\. Откройте \*\*Arduino IDE\*\* → \*\*Файл\*\* → \*\*Настройки\*\* → \*\*Дополнительные ссылки для менеджера плат\*\*.

2\. Добавьте строку:  

&#x20;  `https://files.seeedstudio.com/arduino/package\_seeeduino\_boards\_index.json`

3\. \*\*Инструменты\*\* → \*\*Плата\*\* → \*\*Менеджер плат\*\* → найдите \*\*«Seeed nRF52 Boards»\*\* → установите.

4\. Выберите плату: \*\*Seeed XIAO nRF52840 Sense\*\*.

\## Быстрый старт



1\. \*\*Клонируйте репозиторий\*\*  

&#x20;  `git clone https://github.com/Pau1oo/nrf52840-physiological-monitor.git`



2\. \*\*Откройте скетч\*\*  

&#x20;  Запустите Arduino IDE, откройте файл `nrf52840-physiological-monitor.ino`.



3\. \*\*Соберите аппаратную часть\*\*  

&#x20;  Подключите компоненты согласно схеме из папки `docs/`.  



4\. \*\*Вставьте microSD-карту\*\* (отформатированную в FAT32).



5\. \*\*Выберите правильный COM-порт\*\* и загрузите прошивку.



6\. \*\*Питание\*\* – можно подать через USB‑C (аккумулятор будет заряжаться) или от Li‑Po батареи.
